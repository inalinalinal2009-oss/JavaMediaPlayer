# Auralis — Java Media Player 2.0

Java 25 · JavaFX 25.0.2 · Maven

## Запуск
Требуются JDK 25 и Maven. В корне проекта:

```bash
mvn clean javafx:run
```

## Возможности
- Постоянное хранение медиатеки, плейлистов и последних воспроизведённых файлов в `~/.auralis/library.json`.
- Сохранение пользовательских обложек в `~/.auralis/covers/`.
- Получение названия, исполнителя, альбома и встроенной обложки из метаданных, когда их предоставляет медиадвижок JavaFX.
- Waveform-подобная полоса, формируемая из истории аудиоспектра; клик по ней перематывает трек.
- Четыре режима визуализатора: столбцы, зеркало, волна и кольцо.
- Полноэкранный визуализатор (Esc/F или двойной клик для выхода).
- Горячие клавиши: Space — play/pause; Ctrl+←/→ — предыдущий/следующий; Ctrl+O — добавить файлы; Ctrl+F — полноэкранный визуализатор; Ctrl+, — настройки.
- Drag & drop медиафайлов на список треков.
- Контекстное меню трека: воспроизведение, добавление в плейлист, выбор обложки, удаление.
- Shuffle и Repeat (повтор текущего трека).
- Пульсация обложки в зависимости от низкочастотной энергии.
- Сохранение громкости и выбранного режима визуализатора.
- Девятиполосный эквалайзер.
- PNG-иконки в `src/main/resources/ru/mediaplayer/images/icons/`. Их можно заменить файлами с теми же именами.

## Иконки
Все интерфейсные значки — отдельные PNG с прозрачным фоном. Чтобы заменить значок, сохрани новую картинку в папке `images/icons` под тем же именем. Рекомендуемый размер — 64×64 px; отображаемый размер задаётся в FXML.

## Ограничения
Поддержка контейнеров и метаданных зависит от кодеков, доступных JavaFX на конкретной ОС. Waveform в этой версии — визуализация истории спектра, а не предварительно рассчитанная амплитудная форма всего файла. История и плейлисты сохраняются локально без синхронизации между устройствами.
